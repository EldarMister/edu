# Общие нижние панели

`mobile/src/components/BottomPanel.tsx` — общий измеряемый контейнер.
`BottomSheet` и `FullscreenSheet` сохранены как совместимые точки входа,
поэтому существующие панели используют новый движок без замены действий API.
Полноэкранный лист передаёт `expanded`; обычный лист имеет естественную высоту.

Движение, сопротивление, затемнение и scrollY работают через shared values
на UI-потоке. Открытие ждёт onLayout; закрытие доходит до измеренной высоты
плюс 24 dp. Закрытие, возврат и Reduce Motion используют общие настройки.
Обработчики закрытия защищены токеном поколения и выполняются после выхода.
Смена `visible` снаружи считается уже выполненным запросом владельца:
повторно его onClose не вызывается, onDismiss сообщает об окончании выхода.

Для программного управления новым кодом:

```tsx
const panel = useBottomPanelController();
// panel.open(), panel.close(), panel.switchTo(() => next.open())
return <BottomPanel {...panel.bind} title="Выбор" footer={actions}>
  <PanelScrollView>{content}</PanelScrollView>
</BottomPanel>;
```

`contentKey` меняет шаг внутри того же листа с переходом 32 dp / 220 мс.
`ownerKey` меняется при выборе другого заказа/объекта: это отменяет незавершённое
закрытие предыдущего объекта и защищает новый от старого callback.
`PanelScrollView` / `SheetScrollView` сохраняют refs и существующий onScroll;
`PanelFlatList` / `SheetFlatList` сохраняют виртуализацию. Свайп вниз по списку
двигает панель, если начался в верхней позиции прокрутки. Ручка работает при
любой позиции списка. Горизонтальные элементы используют обычный ScrollView.

История приостанавливает текущий лист до открытия следующего, сохраняя его
React-дерево. После закрытия временного листа предыдущий возвращается.
Выбор сета → настройка → замена → размер и оплата → разделение счёта
подключены к этой схеме. Нижележащие экраны и панели исключены из касаний
и дерева доступности. Попап календаря и боковой стоп-лист остаются своими
типами окон: они не являются нижними панелями.

`persistent` предназначен для постоянной компактной панели над картой;
только ей назначается предел 52% `containerHeight` или измеренного контейнера.
Временные панели ограничены safe area и доступным пространством. Ручка
по умолчанию внутри панели; `handlePlacement="outside"` размещает её над поверхностью.
Для нативных контролов, которым нужен собственный вертикальный жест,
можно отключить drag панели через `draggable={false}`.

Клавиатура: iOS KeyboardAvoidingView/padding; Android компенсирует только
фактическое оставшееся перекрытие после adjustResize. Футер расположен вне
прокрутки. Кнопки действий в озвучке, QR и уведомлении о правах перенесены
в неподвижные футеры.

Короткая проверка: TypeScript и 42 целевых теста (геометрия, реальный hook
жизненного цикла с имитацией native-анимаций, история, корзина и оплата).
Эмуляторы Android и устройства iOS в этом проходе не запускались.
